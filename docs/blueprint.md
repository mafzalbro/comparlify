# **App Name**: Comparlify

## Core Features:

- Landing Page with Animated Hero Section: A visually engaging landing page to showcase Comparlify's value proposition using animations and interactive elements.
- Course Comparison Listing Page: A comprehensive page displaying course comparisons with modern filtering and sorting options (icon-based).
- In-Depth Comparison Detail Page: A dedicated page for each course comparison, providing detailed insights, modern layout, and supplementary information.
- Blog Section: A fully managed blog to share valuable content and resources for course creators.
- AI-Powered Title Generator: A tool using generative AI that assists course creators in generating effective titles for their content.
- AI Chatbot: An AI-powered chatbot with full knowledge of Comparlify.  Acts as a tool for answering user queries and offering personalized recommendations.
- Supporting Pages: Essential pages like 'Welcome', 'Contact', 'About', and 'Privacy' to ensure a complete user experience.

## Style Guidelines:

- Primary color: Soft yellow (#F9E79F) to evoke a friendly and approachable feeling.
- Background color: Very pale yellow (#FAF7F0) for a warm and inviting base.
- Accent color: Muted orange (#E59866) for highlights and call-to-action buttons, providing contrast without being too overwhelming.
- Headline font: 'Belleza' (sans-serif) for titles, and 'Alegreya' (serif) for body text.
- Use a consistent set of custom, playful icons throughout the platform to enhance visual communication.
- Employ a clean, modern layout with generous whitespace and a clear visual hierarchy for easy navigation.
- Incorporate subtle animations and transitions to enhance user engagement and provide visual feedback.
